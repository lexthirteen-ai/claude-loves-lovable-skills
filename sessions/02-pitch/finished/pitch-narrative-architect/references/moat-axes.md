# Moat axes (for slide 8)

When anyone can rebuild your features in a weekend, the features are not the moat. Sort the business into two layers.

**The clonable surface:** the UI, the feature list, generic content, the tech stack. Be honest that this is now cheap.

**The defensible layer:** score each axis 0 to 3. 0 means a stranger starting today matches you, 3 means a clone would need months or years.

| Axis | What it means | 0 | 3 |
|---|---|---|---|
| Audience | People who already know you and will hear about your next thing | none | shows up every time you ship |
| Trust and reputation | People believe you over a stranger with the same screen | unknown | a name people cite |
| Proprietary data | Data or learning a copy cannot get on day one | none | more use makes the product better |
| Owned distribution | Channels you control (email list, community) | rented only | several owned channels that convert |
| Community | People who talk to each other because of you | none | creates value without you in the room |
| Switching costs | What a user loses by leaving | trivial | deeply embedded |
| Brand | A feeling and specificity a generic clone cannot fake | generic | preferred on feel alone |
| Speed of learning | You improve faster than a copy can follow | no edge | you out-learn anyone who copies you |

**For the slide:** lead with the two axes where the honest score is highest, or where you can most credibly grow in the next six months. Name the move, not just the axis. "Every groomer's client history and route preferences live here" is a moat claim. "We have great UX" is not.

If the honest answer to "what would still be yours" is "nothing yet", say so in the notes, and make the slide about the moat you are building and the first step you have already taken.
