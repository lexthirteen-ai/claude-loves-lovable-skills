# Session 02 build guide: Pitch Narrative Architect

**Build block:** 0:45 to 1:15 (30 minutes). Build the skill, run it on your product, then build the web deck in Lovable.

## Before you start
- [ ] Your `brand-system.md` from Session 01 is handy.
- [ ] You know who this pitch is for (investor, partner, pilot customer, leadership) and what you are asking for.

## Build it (12 minutes)
1. New Claude chat. Attach `starter/pitch-narrative-architect/SKILL.md`.
2. Paste the build prompt from [docs/build-your-own.md](../../docs/build-your-own.md#the-build-prompt).
3. Use what we worked through in the 0:15 block: one slide, one claim, one proof point; the ten-slide arc; and the weakest-slide pressure test.
4. Copy `finished/pitch-narrative-architect/references/` into your folder (the moat axes and the output template), then package and install it ([docs/install.md](../../docs/install.md)).

## Check your skill against the finished version
- [ ] Reads `brand-system.md` first and uses its voice
- [ ] Interviews one question at a time, including proof and "what would a copy not take from you"
- [ ] Ten slides, each with claim, proof, on-slide copy, and speaker notes
- [ ] Skim test (headlines only tell the story)
- [ ] Scores proof and names the weakest slide
- [ ] Never invents numbers. Uses `[NEEDS PROOF]` instead
- [ ] Saves `pitch-narrative.md` with a Lovable web-deck prompt at the end

## Test it
New chat:
1. "I need a pitch for my product. Here's my brand system." (attach `brand-system.md`)
2. "I'm pitching my director on an internal tool. Help me build the story."
3. "Which slide in my pitch is weakest?" (after the first run)

## Build the deck in Lovable (rest of the block)
1. New Lovable project. Paste `brand-system.md` into project knowledge.
2. Paste the web-deck prompt from the end of `pitch-narrative.md`.
3. Polish pass (1:15): pacing, the ask slide, and what to cut. Publish and copy the share link.

## Out of time?
Install `finished/pitch-narrative-architect/` as-is and fill in the starter as homework.

## Homework
Send the deck link to one real person before Session 03.
