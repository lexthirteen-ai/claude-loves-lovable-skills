# Session 04 build guide: Founder Site Copywriter

**Build block:** 0:45 to 1:10 (25 minutes). Build the skill, generate your site copy, then build section by section in Lovable. Launch at 1:10.

## Before you start
- [ ] `brand-system.md`, `pitch-narrative.md`, and `prd.md` are handy.
- [ ] You know the one action you want visitors to take.

## Build it (10 minutes)
1. New Claude chat. Attach `starter/founder-site-copywriter/SKILL.md`.
2. Paste the build prompt from [docs/build-your-own.md](../../docs/build-your-own.md#the-build-prompt).
3. Use the 0:00 and 0:15 blocks: the five sections and the order visitors read them, and which pitch slide feeds each section.
4. Copy `finished/founder-site-copywriter/references/` into your folder, then package and install it ([docs/install.md](../../docs/install.md)).

## Check your skill against the finished version
- [ ] Reads all three earlier files and asks four questions if they're missing
- [ ] One action, the same button text everywhere
- [ ] Five sections, each mapped to a pitch slide
- [ ] Layout direction and a Lovable prompt for every section
- [ ] Search basics with length limits
- [ ] Five-second test on the hero
- [ ] Launch checklist, and no fake proof

## Test it
New chat, attach your three files:
1. "Write my website."
2. "My homepage isn't converting. Rewrite the hero." (paste your current hero)

## Build and launch in Lovable
1. Send the page-setup prompt, then one section prompt at a time.
2. 1:10 block: work through the launch checklist and publish.

## The system
You now have four skills that hand off to each other: brand → pitch → PRD → site. See [docs/skill-chain.md](../../docs/skill-chain.md).

## Out of time?
Install `finished/founder-site-copywriter/` as-is and fill in the starter as homework.
