One fictional product carried through all five skills, so you can see what each output looks like and how each file feeds the next. Lather & Lane is made up. Any resemblance to a real business is accidental.

**The brief:** "A booking and route tool for solo mobile dog groomers. Their clients book online, and the groomer gets a day planned in driving order."
